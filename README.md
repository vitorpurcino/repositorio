# 🚀 DevNotes - Central de Comandos

**DevNotes** é um bloco de notas inteligente e moderno, projetado para ajudar desenvolvedores a acessarem rapidamente comandos, guias e cheat sheets essenciais para o dia a dia. Chega de perder tempo procurando no Google aquele comando do Artisan ou aquela diretiva do Blade!

---

## ✨ Funcionalidades

- **🔍 Busca em Tempo Real:** Encontre o que precisa instantaneamente com a barra de pesquisa inteligente.
- **🎨 Design Moderno & Responsivo:** Interface limpa, intuitiva e totalmente adaptada para diferentes dispositivos.
- **🌙 Modo Escuro Integrado:** Conforto visual garantido para longas sessões de codificação.
- **📚 Curadoria Especializada:**
  - **Laravel Artisan:** Lista completa de comandos para impulsionar seu workflow.
  - **Blade Engine:** Guia rápido de diretivas e lógica de template.
  - **Git SCM:** Comandos essenciais para automação e controle de versão.
- **⚡ Micro-interações:** Feedback visual suave e animações premium.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais para máxima performance e compatibilidade:

- **HTML5:** Estrutura semântica e SEO.
- **CSS3:** Estilização avançada com Flexbox, Grid e variáveis CSS para temas.
- **JavaScript (Vanilla):** Lógica de busca, manipulação de DOM e controle de tema (sem dependências externas).

## 🚀 Como Executar

Não é necessário instalar nenhuma dependência ou servidor! Para visualizar o projeto:

1. Clone o repositório ou baixe os arquivos.
2. Localize o arquivo `index.html` no diretório raiz.
3. Clique duas vezes para abrir no seu navegador de preferência.
