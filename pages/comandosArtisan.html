Cheat Sheet Completo do Artisan – Laravel 12.52.0

Dica: Use php artisan list para ver todos os comandos disponíveis. Use php artisan help [comando] para detalhes.

🔧 Comandos Básicos

Comando Descrição
php artisan about Exibe informações básicas sobre a aplicação
php artisan clear-compiled Remove o arquivo de classes compiladas
php artisan completion Gera script de auto-completar para shell
php artisan db Inicia uma sessão CLI do banco de dados
php artisan docs Acessa a documentação do Laravel
php artisan down Coloca a aplicação em modo manutenção/demo
php artisan env Exibe o ambiente atual (ex.: local, production)
php artisan help Exibe ajuda para um comando específico
php artisan inspire Exibe uma frase inspiradora
php artisan list Lista todos os comandos disponíveis
php artisan migrate Executa as migrações do banco
php artisan optimize Cacheia bootstrap, configuração e metadados
php artisan pail Monitora os logs da aplicação
php artisan reload Recarrega serviços em execução
php artisan serve Serve a aplicação no servidor PHP de desenvolvimento
php artisan test Executa os testes da aplicação
php artisan tinker Interage com a aplicação via REPL
php artisan up Remove o modo manutenção

⚙️ Auth

Comando Descrição
php artisan auth:clear-resets Limpa tokens expirados de reset de senha

🗃️ Cache

Comando Descrição
php artisan cache:clear Limpa o cache da aplicação
php artisan cache:forget Remove um item do cache
php artisan cache:prune-stale-tags Remove tags de cache obsoletas (Redis)

📬 Channel

Comando Descrição
php artisan channel:list Lista todos os canais privados registrados

⚙️ Config

Comando Descrição

php artisan config:show Exibe valores de configuração

🔧 DB

Comando Descrição
