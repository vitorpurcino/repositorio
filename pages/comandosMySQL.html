📊 Guia Completo de MySQL — DDL, DML, JOINS, VIEWS e Funções

🔍
Dica: MySQL é um SGBDR (Sistema de Gerenciamento de Banco de Dados Relacional) que segue o padrão SQL. Pressione Ctrl+F para buscar conteúdo específico nesta página.

📚 Conceitos Fundamentais

  • Banco de Dados: Coleção estruturada de dados organizados em tabelas.
  • Tabela: Estrutura com linhas (registros) e colunas (campos).
  • Chave Primária (PK): Identifica unicamente cada registro.
  • Chave Estrangeira (FK): Referencia a chave primária de outra tabela.
  • Índice: Acelera buscas em grandes volumes de dados.
  • View (Visão): Consulta armazenada que se comporta como uma tabela virtual.
  • Transação: Sequência de operações que devem ser executadas como um bloco atômico.

🔤 DDL - Data Definition Language (Definição de Dados)

DDL é utilizado para criar, modificar e remover estruturas de banco de dados.

CREATE TABLE

Comando Descrição
CREATE TABLE usuarios (id INT PRIMARY KEY AUTO_INCREMENT, nome VARCHAR(100)) Cria uma nova tabela com coluna de ID auto-incremento
CREATE TABLE IF NOT EXISTS usuarios (...) Cria tabela apenas se não existir
CREATE TABLE produtos AS SELECT * FROM backup_produtos Cria tabela copiando dados de outra tabela

Tipos de Dados Comuns

Tipo Descrição Exemplo
INT Número inteiro de 32 bits (-2.147.483.648 a 2.147.483.647) INT
BIGINT Número inteiro de 64 bits BIGINT
DECIMAL(p,s) Número decimal com precisão e escala DECIMAL(10,2) = 12345678.90
FLOAT / DOUBLE Números de ponto flutuante FLOAT, DOUBLE
VARCHAR(n) String variável até n caracteres VARCHAR(100)
TEXT Texto grande (até 65.535 caracteres) TEXT
DATE Data no formato YYYY-MM-DD 2024-12-15
DATETIME Data e hora YYYY-MM-DD HH:MM:SS 2024-12-15 14:30:00
TIMESTAMP Timestamp automático (se não preenchido, usa agora) TIMESTAMP DEFAULT CURRENT_TIMESTAMP
BOOLEAN / BOOL Booleano (0 ou 1) BOOLEAN
ENUM('valor1','valor2') Lista de valores permitidos ENUM('ativo','inativo')
JSON Dados em formato JSON {"chave": "valor"}

ALTER TABLE

Comando Descrição
ALTER TABLE usuarios ADD COLUMN email VARCHAR(100) Adiciona uma nova coluna
ALTER TABLE usuarios DROP COLUMN email Remove uma coluna
ALTER TABLE usuarios RENAME COLUMN nome TO nome_completo Renomeia uma coluna
ALTER TABLE usuarios MODIFY COLUMN nome VARCHAR(150) Modifica o tipo de uma coluna
ALTER TABLE usuarios ADD PRIMARY KEY (id) Adiciona chave primária
ALTER TABLE usuarios ADD UNIQUE(email) Adiciona constraint UNIQUE
ALTER TABLE usuarios ADD INDEX idx_email(email) Cria um índice

DROP e TRUNCATE

Comando Descrição
DROP TABLE usuarios Remove a tabela completamente (estrutura + dados)
DROP TABLE IF EXISTS usuarios Remove a tabela apenas se existir
TRUNCATE TABLE usuarios Remove todos os dados mas mantém a estrutura
DROP DATABASE banco_dados Remove o banco de dados inteiro

✏️ DML - Data Manipulation Language (Manipulação de Dados)

DML é utilizado para inserir, atualizar, deletar e consultar dados.

INSERT - Inserindo Dados

Comando Descrição
INSERT INTO usuarios (id, nome, email) VALUES (1, 'João', 'joao@email.com') Insere um registro completo
INSERT INTO usuarios VALUES (2, 'Maria', 'maria@email.com') Insere sem especificar colunas (ordem completa)
INSERT INTO usuarios (nome, email) VALUES ('Ana', 'ana@email.com') Insere apenas colunas especificadas (ID auto-incrementa)
INSERT INTO usuarios (nome, email) VALUES ('Carlos', 'carlos@email.com'), ('Diana', 'diana@email.com') Insere múltiplos registros de uma vez
INSERT INTO usuarios SELECT * FROM usuarios_backup Insere dados vindo de um SELECT

UPDATE - Atualizando Dados

Comando Descrição
UPDATE usuarios SET email = 'novo@email.com' WHERE id = 1 Atualiza email do usuário com ID 1
UPDATE usuarios SET nome = 'João Silva', email = 'joao.silva@email.com' WHERE id = 1 Atualiza múltiplas colunas
UPDATE usuarios SET ativo = 0 WHERE YEAR(data_criacao) < 2023 Atualiza com condição complexa
UPDATE usuarios SET saldo = saldo + 100 WHERE categoria = 'premium' Atualiza com expressão (incremento)

DELETE - Deletando Dados

Comando Descrição
DELETE FROM usuarios WHERE id = 1 Delete um registro específico
DELETE FROM usuarios WHERE email LIKE '%@domain.com' Delete múltiplos registros com padrão
DELETE FROM usuarios Delete TODOS os registros (cuidado!)
DELETE FROM usuarios WHERE id IN (1, 2, 3) Delete registros específicos por ID

🔍 SELECT - Consultando Dados

SELECT Básico

Comando Descrição
SELECT * FROM usuarios Seleciona todas as colunas de todos os registros
SELECT id, nome FROM usuarios Seleciona apenas ID e nome
SELECT DISTINCT categoria FROM produtos Seleciona valores únicos (sem duplicatas)
SELECT * FROM usuarios LIMIT 10 Limita resultado a 10 registros
SELECT * FROM usuarios LIMIT 10 OFFSET 20 Paginação: pula 20 registros, retorna 10
SELECT * FROM usuarios ORDER BY nome ASC Ordena por nome em ordem alfabética crescente
SELECT * FROM usuarios ORDER BY data_criacao DESC Ordena por data em ordem decrescente

WHERE e Operadores de Comparação

Operador Descrição Exemplo
= Igualdade WHERE status = 'ativo'
!= ou <> Não igual WHERE status != 'inativo'
> Maior que WHERE preco > 100
< Menor que WHERE idade < 18
>= Maior ou igual WHERE saldo >= 50
<= Menor ou igual WHERE quantidade <= 10
BETWEEN a AND b Entre dois valores (inclusivo) WHERE preco BETWEEN 50 AND 150
IN (...) Dentro de uma lista WHERE status IN ('ativo', 'pendente')
LIKE Busca com padrão (% = qualquer caractere, _ = um caractere) WHERE nome LIKE 'Jo%'
REGEXP Expressão regular WHERE email REGEXP '^[a-z]+@domain\.com$'

Operadores Lógicos

Operador Descrição Exemplo
AND Ambas as condições devem ser verdadeiras WHERE idade > 18 AND status = 'ativo'
OR Pelo menos uma condição deve ser verdadeira WHERE categoria = 'A' OR categoria = 'B'
NOT Inverte a condição WHERE NOT status = 'inativo'

🔗 JOINS - Relacionando Tabelas

JOINs combinam dados de duas ou mais tabelas baseado em uma coluna relacionada.

INNER JOIN

Tipo Descrição Exemplo
INNER JOIN Retorna apenas os registros que existem em ambas as tabelas SELECT u.nome, p.titulo FROM usuarios u INNER JOIN posts p ON u.id = p.usuario_id
JOIN Sinônimo para INNER JOIN SELECT * FROM usuarios JOIN posts ON usuarios.id = posts.usuario_id

LEFT JOIN

Tipo Descrição Exemplo
LEFT JOIN (LEFT OUTER JOIN) Retorna todos os registros da tabela esquerda, mesmo que não tenham correspondência SELECT u.nome, p.titulo FROM usuarios u LEFT JOIN posts p ON u.id = p.usuario_id

RIGHT JOIN

Tipo Descrição Exemplo
RIGHT JOIN (RIGHT OUTER JOIN) Retorna todos os registros da tabela direita, mesmo que não tenham correspondência SELECT u.nome, p.titulo FROM usuarios u RIGHT JOIN posts p ON u.id = p.usuario_id

FULL OUTER JOIN

Tipo Descrição Workaround MySQL
FULL OUTER JOIN Retorna todos os registros de ambas as tabelas SELECT * FROM usuarios u LEFT JOIN posts p ON u.id = p.usuario_id UNION SELECT * FROM usuarios u RIGHT JOIN posts p ON u.id = p.usuario_id

CROSS JOIN

Tipo Descrição Exemplo
CROSS JOIN Produto cartesiano: combina cada linha com cada linha da outra tabela SELECT * FROM cores CROSS JOIN tamanhos (se 3 cores e 2 tamanhos = 6 resultados)

SELF JOIN

Tipo Descrição Exemplo
SELF JOIN Join de uma tabela com ela mesma SELECT e1.nome AS funcionario, e2.nome AS gerente FROM funcionarios e1 JOIN funcionarios e2 ON e1.gerente_id = e2.id

📊 Funções de Agregação

Estas funções retornam um valor agregado dos registros.

Função Descrição Exemplo
COUNT() Conta o número de registros SELECT COUNT(*) FROM usuarios (conta total)
COUNT(coluna) Conta não-nulos em uma coluna SELECT COUNT(email) FROM usuarios
SUM() Soma valores SELECT SUM(preco) FROM produtos WHERE categoria = 'eletrônicos'
AVG() Calcula a média SELECT AVG(preco) FROM produtos
MIN() Retorna o valor mínimo SELECT MIN(preco) FROM produtos
MAX() Retorna o valor máximo SELECT MAX(preco) FROM produtos
GROUP_CONCAT() Concatena valores separados por vírgula SELECT GROUP_CONCAT(nome) FROM usuarios

📈 GROUP BY e HAVING

Cláusula Descrição Exemplo
GROUP BY Agrupa resultados por coluna(s) SELECT categoria, COUNT(*) FROM produtos GROUP BY categoria
HAVING Filtra grupos (como WHERE mas para agregações) SELECT categoria, COUNT(*) FROM produtos GROUP BY categoria HAVING COUNT(*) > 5
GROUP BY ... WITH ROLLUP Inclui total geral no resultado SELECT categoria, COUNT(*) FROM produtos GROUP BY categoria WITH ROLLUP

🔷 Funções de String

Função Descrição Exemplo
CONCAT(str1, str2, ...) Concatena strings SELECT CONCAT(nome, ' - ', email) FROM usuarios
UPPER() Converte para maiúscula SELECT UPPER(nome) FROM usuarios
LOWER() Converte para minúscula SELECT LOWER(email) FROM usuarios
LENGTH() Retorna o comprimento da string SELECT nome, LENGTH(nome) FROM usuarios WHERE LENGTH(nome) > 10
SUBSTRING(str, pos, len) Extrai substring SELECT SUBSTRING(email, 1, 5) FROM usuarios
TRIM() / LTRIM() / RTRIM() Remove espaços em branco SELECT TRIM(nome) FROM usuarios
REPLACE(str, from, to) Substitui texto SELECT REPLACE(email, '@domain.com', '@newdomain.com') FROM usuarios

📅 Funções de Data

Função Descrição Exemplo
NOW() Retorna data e hora atual SELECT NOW()
CURDATE() Retorna a data atual SELECT CURDATE()
CURTIME() Retorna a hora atual SELECT CURTIME()
DATE_ADD(date, INTERVAL n UNIT) Adiciona intervalo à data SELECT DATE_ADD(NOW(), INTERVAL 7 DAY)

🔢 Funções Matemáticas

Função Descrição Exemplo

❌ Tratamento de NULOS (NULL)

NULL representa a ausência de valor. É diferente de zero, string vazia ou false.

Operação Descrição Exemplo
IS NULL Verifica se valor é nulo SELECT * FROM usuarios WHERE email IS NULL
IS NOT NULL Verifica se valor NÃO é nulo SELECT * FROM usuarios WHERE email IS NOT NULL
IFNULL(col, valor_default) Retorna valor_default se col for NULL SELECT IFNULL(telefone, 'Não informado') FROM usuarios
COALESCE(col1, col2, col3, ...) Retorna o primeiro valor não-nulo SELECT COALESCE(telefone, email, 'Sem contato') FROM usuarios
IF(condição, valor_true, valor_false) Operador condicional SELECT nome, IF(ativo = 1, 'Ativo', 'Inativo') FROM usuarios

💾 VIEWS - Consultas Armazenadas

Uma VIEW é uma consulta virtual reutilizável que se comporta como uma tabela.

Operação Descrição Exemplo
CREATE VIEW nome_view AS SELECT ... Cria uma view CREATE VIEW usuarios_ativos AS SELECT * FROM usuarios WHERE ativo = 1
SELECT * FROM nome_view Consulta uma view SELECT * FROM usuarios_ativos
DROP VIEW nome_view Remove uma view DROP VIEW usuarios_ativos
ALTER VIEW nome_view AS SELECT ... Altera uma view ALTER VIEW usuarios_ativos AS SELECT id, nome FROM usuarios WHERE ativo = 1
SHOW VIEWS Lista todas as views SHOW VIEWS

🔍 SUBCONSULTAS

Subconsultas são SELECT aninhados dentro de outras instruções SQL.

Subconsultas em SELECT

Tipo Descrição Exemplo
Escalar Retorna um valor único SELECT nome, (SELECT COUNT(*) FROM posts WHERE posts.usuario_id = usuarios.id) AS total_posts FROM usuarios
Lista Retorna múltiplas linhas SELECT * FROM usuarios WHERE id IN (SELECT usuario_id FROM posts)

Subconsultas em WHERE

Operador Descrição Exemplo
IN Valor está dentro do resultado da subconsulta SELECT * FROM usuarios WHERE id IN (SELECT usuario_id FROM posts WHERE status = 'publicado')
NOT IN Valor NÃO está no resultado SELECT * FROM usuarios WHERE id NOT IN (SELECT usuario_id FROM posts)
EXISTS Verifica se subconsulta retorna algum resultado SELECT * FROM usuarios WHERE EXISTS (SELECT 1 FROM posts WHERE posts.usuario_id = usuarios.id)
NOT EXISTS Verifica se subconsulta NÃO retorna resultado SELECT * FROM usuarios WHERE NOT EXISTS (SELECT 1 FROM posts WHERE posts.usuario_id = usuarios.id)
=, >, <, >=, <=, != Comparação com resultado escalar SELECT * FROM produtos WHERE preco > (SELECT AVG(preco) FROM produtos)

🔄 UNION e UNION ALL

Operador Descrição Exemplo
UNION Combina resultados de duas consultas (sem duplicatas) SELECT nome FROM usuarios UNION SELECT titulo FROM posts
UNION ALL Combina resultados (mantém duplicatas) SELECT nome FROM usuarios_2023 UNION ALL SELECT nome FROM usuarios_2024

⚙️ Operações com CASE

Sintaxe Descrição Exemplo
CASE WHEN ... THEN ... ELSE ... END Lógica condicional no SELECT SELECT nome, CASE WHEN idade < 18 THEN 'Menor' ELSE 'Maior' END FROM usuarios
CASE expr WHEN val1 THEN result1 ... CASE simples SELECT CASE status WHEN 1 THEN 'Ativo' WHEN 0 THEN 'Inativo' END FROM usuarios

🔐 Transações (TRANSACTIONS)

Comando Descrição Exemplo

📋 Exemplo Prático Completo

-- Criar tabelas relacionadas
CREATE TABLE usuarios (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nome VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    data_criacao TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE posts (
    id INT PRIMARY KEY AUTO_INCREMENT,
    usuario_id INT NOT NULL,
    titulo VARCHAR(200) NOT NULL,
    conteudo TEXT,
    data_publicacao DATE,
    FOREIGN KEY (usuario_id) REFERENCES usuarios(id)
);

-- Inserir dados
INSERT INTO usuarios (nome, email) VALUES 
    ('João Silva', 'joao@email.com'),
    ('Maria Santos', 'maria@email.com');

INSERT INTO posts (usuario_id, titulo, conteudo, data_publicacao) VALUES
    (1, 'SQL Básico', 'Aprenda o básico de SQL...', '2024-01-15'),
    (1, 'MySQL Avançado', 'Técnicas avançadas...', '2024-02-10'),
    (2, 'Database Design', 'Design de banco de dados...', '2024-01-20');

-- Consulta com JOIN e agregação
SELECT 
    u.nome,
    COUNT(p.id) AS total_posts,
    MAX(p.data_publicacao) AS ultimo_post
FROM usuarios u
LEFT JOIN posts p ON u.id = p.usuario_id
GROUP BY u.id, u.nome
HAVING COUNT(p.id) > 0
ORDER BY total_posts DESC;

💡 Boas Práticas

  • Use PRIMARY KEY: Sempre defina uma chave primária para cada tabela.
  • Use FOREIGN KEY: Manter integridade referencial entre tabelas.
  • Evite valores NULL quando possível: Use DEFAULT ou NOT NULL.
  • Normalize dados: Avoid duplicação desnecessária.
  • Use índices com sabedoria: Índices aceleram buscas mas desaceleram inserções.
  • Use LIMIT em testes: Sempre teste queries com LIMIT antes de executar sem limite.
  • Comente queries complexas: Facilita manutenção posterior.
  • Use transações para operações críticas: Garante atomicidade de múltiplas operações.
  • Valide dados no código antes de INSERT: Previne dados inválidos no banco.
  • Use EXPLAIN para otimizar queries: EXPLAIN SELECT ... mostra plano de execução.
