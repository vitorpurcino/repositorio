Sheet Completo do Git — Comandos, Conceitos e Exemplos

Dica: Use git --help [comando] ou git help [comando] para ajuda detalhada. Use git status sempre que tiver dúvida do estado do repositório.

📦 Conceitos Básicos do Git

  • Repositório (Repo): Pasta com histórico de versões do projeto.
  • Working Directory: Arquivos que você está editando.
  • Staging Area (Index): Área onde você prepara os arquivos para o commit.
  • Commit: Ponto de salvamento no histórico (com mensagem).
  • Branch: Linha de desenvolvimento paralela (ex: main, feature/login).
  • Remote: Repositório remoto (ex: GitHub, GitLab).
  • HEAD: Ponteiro para o último commit do branch atual.
  • Origin: Nome padrão do repositório remoto.
  • SHA-1: Hash único de cada commit (ex: abc123...).

🔧 Comandos Básicos

Comando Descrição
git init Inicia um novo repositório Git
git clone [url] Clona um repositório remoto
git status Mostra estado dos arquivos (modificados, novos, staged)
git add [arquivo] Adiciona arquivo ao staging area
git add . Adiciona todos os arquivos modificados/novos ao staging
git commit -m "mensagem" Cria um commit com mensagem
git log Mostra histórico de commits
git log --oneline Mostra histórico em uma linha por commit
git diff Mostra diferenças entre working directory e staging
git diff --staged Mostra diferenças entre staging e último commit

🔄 Branches e Merge

Comando Descrição
git branch Lista todos os branches
git branch [nome] Cria um novo branch
git checkout [branch] Muda para o branch especificado
git checkout -b [nome] Cria e muda para um novo branch
git merge [branch] Mescla um branch no atual
git merge --no-ff [branch] Mescla com uma mensagem de merge (não fast-forward)
git merge --abort Aborta um merge em andamento
git pull Busca e mescla repositório remoto
git pull --rebase Busca e rebaseia o histórico
git push Envia commits para o repositório remoto
git push origin [branch] Envia um branch específico

🛠️ Comandos Avançados

Comando Descrição
git rebase [branch] Reescreve commits do branch atual sobre o branch especificado
git rebase -i [branch] Abre editor para interação com commits (squash, edit, reword, etc.)
git reset --soft [commit] Move HEAD para o commit, mantendo alterações no staging
git reset --mixed [commit] Move HEAD para o commit, desfaz staging
git reset --hard [commit] Move HEAD para o commit, desfaz tudo (working directory e staging)
git reset --hard HEAD~1 Desfaz o último commit
git revert [commit] Cria um novo commit que desfaz as alterações do commit especificado
git cherry-pick [commit] Copia um commit específico para o branch atual
git stash Salva alterações pendentes (working directory e staging)
git stash pop Recupera o último stash
git stash list Lista todos os stashes
git bisect start Inicia busca binária para encontrar bug
git bisect good Marca commit como "funcionando"
git bisect bad Marca commit como "com bug"
git bisect reset Reseta a busca binária
git reflog Mostra histórico de movimentos do HEAD
git log --graph --oneline --all Mostra histórico com visualização de branches
git log --pretty=format:"%h - %an, %ar : %s" Formata histórico com detalhes

🔐 Segurança e Autenticação

Comando Descrição
git config --global user.name "Seu Nome" Configura nome de usuário global
git config --global user.email "seu@email.com" Configura email global
git config --global credential.helper store Armazena credenciais para futuros acessos
git config --global http.sslVerify false Desativa verificação SSL (não recomendado)
git config --global http.sslVerify true Reativa verificação SSL (recomendado)

📦 Comandos de Revisão

Comando Descrição
git show [commit] Mostra detalhes de um commit
git show [commit]:[arquivo] Mostra conteúdo de um arquivo em um commit específico
git show [commit] -- [arquivo] Mostra alterações de um arquivo em um commit
git diff [commit1] [commit2] Mostra diferenças entre dois commits
git diff [commit1] [commit2] -- [arquivo] Mostra diferenças de um arquivo entre dois commits

📦 Comandos de Revisão de Histórico

Comando Descrição
git log --graph --oneline --all Mostra histórico com visualização de branches
git log --pretty=format:"%h - %an, %ar : %s" Formata histórico com detalhes
git log --since="2 weeks ago" Mostra commits dos últimos 2 semanas
git log --author="nome" Mostra commits de um autor específico
git log --grep="mensagem" Mostra commits com mensagem contendo "mensagem"

📦 Comandos de Revisão de Arquivos

Comando Descrição
git blame [arquivo] Mostra quem modificou cada linha do arquivo
git blame [arquivo] -L 10,20 Mostra quem modificou linhas 10 a 20 do arquivo
git blame [arquivo] -w Ignora espaços em branco ao analisar mudanças

📦 Comandos de Revisão de Tags

Comando Descrição
git tag Lista todas as tags
git tag -a v1.0 -m "Versão 1.0" Cria uma tag anotada
git tag -s v1.0 -m "Versão 1.0" Cria uma tag assinada
git push origin --tags Envia todas as tags para o repositório remoto
git push origin v1.0 Envia uma tag específica

📦 Comandos de Revisão de Remotos

Comando Descrição
git remote -v Mostra remotos configurados
git remote add origin [url] Adiciona um novo remoto
git remote remove origin Remove um remoto
git remote set-url origin [url] Altera a URL de um remoto

git submodule update --init Atualiza submodules
