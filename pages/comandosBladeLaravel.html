Comandos e Diretivas do Blade no Laravel

🔁 Estruturas de Controle

Condicionais

Diretiva Descrição
@if / @elseif / @else / @endif Condicional padrão
@unless / @endunless Executa se a condição for falsa
@isset / @endisset Verifica se variável está definida
@empty / @endempty Verifica se variável está vazia 
@if($user->isAdmin())
    <p>Admin</p>
@elseif($user->isModerator())
    <p>Moderador</p>
@else
    <p>Usuário</p>
@endif

@unless($user->isLoggedIn())
    <p>Por favor, faça login.</p>
@endunless

Switch

@switch($status)
    @case('ativo')
        <p>Ativo</p>
        @break
    @case('inativo')
        <p>Inativo</p>
        @break
    @default
        <p>Desconhecido</p>
@endswitch

🔄 Loops

Diretiva Descrição
@for / @endfor Loop numérico
@foreach / @endforeach Itera sobre coleções
@forelse / @empty / @endforelse foreach com fallback para vazio
@while / @endwhile Loop condicional
@break Interrompe o loop
@continue Pula para a próxima iteração 
@foreach($users as $user)
    <p>{{ $user->name }}</p>
@endforeach

@forelse($products as $product)
    <p>{{ $product->name }}</p>
@empty
    <p>Nenhum produto encontrado.</p>
@endforelse
Dentro de loops, a variável $loop fornece informações úteis como $loop->index, $loop->first, $loop->last, $loop->count, etc.

📤 Exibição de Dados

Diretiva / Sintaxe Descrição
{{ $var }} Exibe valor com escape HTML
{!! $var !!} Exibe valor sem escape (HTML bruto)
{{ $var ?? 'padrão' }} Exibe valor ou padrão se nulo
@{{ }} Escapa as chaves (útil com Vue/Angular) 
{{ $user->name }}          {{-- com escape --}}
{!! $user->bio !!}         {{-- sem escape --}}
{{ $title ?? 'Sem título' }}
@{{ variavel }}            {{-- renderiza literalmente: {{ variavel }} --}}

🧩 Layouts e Componentes

Diretiva Descrição
@extends('layout') Herda um layout base
@section / @endsection Define uma seção de conteúdo
@yield('nome') Marca onde a seção será inserida
@include('view') Inclui outra view
@includeIf Inclui somente se a view existir
@includeWhen Inclui condicionalmente
@includeUnless Inclui se condição for falsa
@each Inclui view para cada item de coleção 
<!-- layout.blade.php -->
<html>
<body>
    @yield('content')
</body>
</html>

<!-- page.blade.php -->
@extends('layout')

@section('content')
    <p>Este é o conteúdo da página.</p>
@endsection
